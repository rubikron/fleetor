- **What.** `fleet task edit <n> --outcome | --crit-t… | --crit-s…` replaces each named field whole. It writes one `edited` chain entry per field that actually changes, holding the field's full old and full new value. An edit that changes nothing is refused and writes nothing. Edit authority is the creator, orch on a worker's task, the operator on any. `fleet task comment <n> "<text>"` is open to anyone and moves neither status nor owner. `update` now requires `--status`; a note-only update is refused and points at `comment`. `list --open` and `--mine` filter on the CLI side. Both briefs call the unit a task (was "block"), teach numbers as bare `14`, and teach each role only its own subcommands: orch gets post, edit and the authority rules; a worker gets show, take up, done and comment.
- **Why.** Whole-field replace is the form a model gets right: no positions to miscount. Storing both full values means a lowered bar is readable from the chain alone.
- **Measured, in characters.** DeepSeek is no longer used, so D-064's token tripwire (orch 3,800, worker 2,200) can no longer be measured in its own unit. Rendered with `count.py`'s own substitution and no network call: orch 15,806 → 17,112 characters (+8.3%), worker 8,583 → 8,835 (+2.9%). The tripwire is restated in rendered characters with D-064's ~3.6% headroom: **orch 17,700, worker 9,150**. It is still a drift tripwire checked by hand, not a test.
- **Deferred.** The worker rule against taking up an in-progress task orch did not hand over, release and `{startup_tasks}` (S2); reviewers and receipts in the chain (S3); worker-opened tasks in the worker brief (S4).
- **Reverses if.** Live runs show orch dropping criteria by forgetting to restate them on an edit.
