id: D-113
title: "S4: flag, remove, restore and attach are chain entries; removed is a fifth status set only by a removal; the brief tripwire is restated"
phase: S4
status: alive
---

- **Flag.** `fleet task flag 14 "<reason>"` writes a `flagged` entry. Anyone, on a goal or a task; the reason is required. It moves neither status nor owner. A row shows "flagged by N", where N is the number of different panes that flagged it, the operator included.
- **Remove and restore.** `fleet task remove 14 "<reason>"` writes a `removed` entry and the status becomes `removed`; the reason is required. `fleet task restore 14 ["<reason>"]` writes `restored` and brings back the status the task had; the owner is never cleared by a removal. orch and the operator, and orch never on a task the operator opened. `--status removed` is refused with the command to use instead.
- **A removed task is hidden, not gone.** `fleet task list` leaves it out unless `--removed` asks for only those; `fleet task show` always prints it. The Tasks view leaves it out of the list and out of its goal's counts, and shows it under a "Removed" filter with its whole chain and a Restore button. It never counts as open.
- **Attach.** `fleet task edit 14 --parent 11` writes an `attached` entry with the old and new goal. It has the reviewer's rule, not the edit rule: orch and the operator, on any task. The parent must be a goal that exists.
- **Worker-opened tasks.** Already allowed since S1 (unowned, goal optional); the worker brief now teaches it, with flag, and says a `removed` task is not worked on.
- **Story 74.** The list also filters by owner (any, unowned, or a pane). The status filter was already there.
- **Measured, in rendered characters.** orch 19,321 with the longest startup text, worker 9,954. Both pass D-106's tripwire (18,900 and 9,750), so it is restated with the same ~3.6% headroom: **orch 20,000, worker 10,300**.
- **Not built here.** An operator control for writing a verdict.
- **Reverses if.** Agents work on removed tasks because the status alone does not stop them; a removal would then also clear the owner or message them, within D-110.
