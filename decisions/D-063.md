- **What changed.** Two claims in WP-12 are corrected by the rewind harness's own measurement (`~/harness/fleetor-eval/NOTES.md`, 2026-08-07). (1) The answer key was called "airtight and free." It is free and **not airtight**: the pinned tree names its own upstream in six files and states its version, and GitHub serves arbitrary SHAs to `git fetch`, so a deliberate clone or a fetch-by-SHA retrieves everything the shallow clone withheld. Scrubbing the upstream identity is not available as a fix — the information that makes the hole possible *is the project*. (2) Case 5 said the grader must be frozen across generations; that is necessary and **not sufficient**, because judging weights are per-mission, and the same mission run twice is contaminated by the previous generation's branches and archived reasoning.
- **Why the default lost.** Both were reasoned, not measured, and a spike measured otherwise. `building.md` §4: where a spike and a plan disagree, the spike wins. The first claim mattered because "airtight" would have justified skipping the audit that is now the actual mitigation; the second mattered because it silently invalidates every generation-over-generation number the loop would otherwise produce.
- **What follows.** The answer key's mitigation is a **post-hoc audit** — a clone of upstream or a fetch-by-SHA appearing in the run's archived transcripts voids that run — not network egress control. And a real generation comparison needs **pairs of missions of matched difficulty**, which nothing in the arc builds yet; until it does, generation-over-generation claims are qualitative and only within-generation findings rest on measurement.
- **What would reverse it.** For the first: a mission source where the target's identity is genuinely separable from its content, which would make absence enforce rather than merely deter. For the second: a demonstrated way to build matched mission pairs, or evidence that re-running one mission after a full `~/.fleetor` reset and a fresh clone is uncontaminated enough to compare.
