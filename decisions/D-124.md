- **What.** `.github/workflows/ci.yml` runs three jobs on `macos-latest` for PRs into and pushes to `master`: `crates` (fmt, clippy `-D warnings`, `cargo test --workspace --locked`), `shell` (the same for `src-tauri`, after `npm ci && npm run build`), and `frontend` (`npm run build`). `rustfmt.toml` sets `use_small_heuristics = "Max"`, the style the code was already closest to; the one-time fmt commit is in `.git-blame-ignore-revs`. `rust-version` moves to 1.82, because the code uses `Option::is_none_or`.
- **Why.** The operator's call, 2026-10-18. No CI existed, and the tree had stopped compiling once without anything noticing (`Installation.path`).
- **The vendor tier skips in CI.** `codex` and `claude` are not installed, so D-081's banner prints and nothing is measured. Installing `codex` would only bring back D-087's known-red arms.
- **Still to land.** G1, a test that nothing is typed into a pane at launch (D-110). G2, every decision file has a matching `INDEX.md` row and status. G3, a CI step that fails when an existing migration is edited. G4, every doc is listed in `docs/README.md` (D-057). Then packaging on `workflow_dispatch`, and the jobs become required checks after their first green run. A check for timeouts on the delivery path (D-034) was considered and dropped as too fragile.
- **Reverses if.** macOS minutes or the real-pty suite's flakiness make the shell job untenable; the fallback is Linux for `crates` and `frontend`, with macOS kept for `shell`.
