- **What.** `.github/workflows/ci.yml` runs three jobs on `macos-latest` for PRs into and pushes to `master`: `crates` (fmt, clippy `-D warnings`, `cargo test --workspace --locked`), `shell` (the same for `src-tauri`, after `npm ci && npm run build`), and `frontend` (`npm run build`). `rustfmt.toml` sets `use_small_heuristics = "Max"`, the style the code was already closest to; the one-time fmt commit is in `.git-blame-ignore-revs`. `rust-version` moves to 1.82, because the code uses `Option::is_none_or`. `rust-toolchain.toml` pins 1.95.0 so a new stable's lints cannot turn CI red overnight.
- **Why.** The operator's call, 2026-10-18. No CI existed, and the tree had stopped compiling once without anything noticing (`Installation.path`).
- **The vendor tier skips in CI.** `codex` and `claude` are not installed, so D-081's banner prints and nothing is measured. Installing `codex` would only bring back D-087's known-red arms.
- **G2 and G4 landed** as `src-tauri/tests/doc_indexes.rs`. G2 cannot see a decision whose file and row were deleted together; that needs git history, like G3.
- **Guards on the base branch** (`.github/workflows/guards.yml`, `scripts/ci/guards.py`, operator's call 2026-10-18). A deleted decision always fails. Without the `ci-reviewed` label, these also fail: an edited migration (G3; the base's `MIGRATIONS` must be a prefix of the PR's), a decision changed beyond its `status` line, or a change to the CI surface. The CI surface is `.github/`, `scripts/ci/`, `rust-toolchain.toml`, `rustfmt.toml`, `.git-blame-ignore-revs`, and every path a decision names in `guard:`. A CI-surface change also needs a decision file in the same PR, label or not. The label means "I reviewed this"; nobody else has to approve, because the author can't approve their own PR and no second reviewer is routine yet.
- **G1 landed** as `src-tauri/tests/no_launch_typing.rs`, D-110's `guard:`: an allowlist of every production call site that can put bytes on a pane's pty or ask the hub to deliver. It reads source, not a running launch (operator's call, 2026-10-18). D-098's bring-up press runs before any message exists and is allowed as a terminal mechanic, along with D-097's colour replies. A decision titled `STANDING RULE` must name a `guard:` (G2).
- **Packaging** is `.github/workflows/package.yml`, run by hand (`workflow_dispatch`): `npm run package`, with the unsigned `.app` uploaded as an artifact.
- **Still to land.** The jobs become required checks after their first green run. A check for timeouts on the delivery path (D-034) was considered and dropped as too fragile.
- **Reverses if.** macOS minutes or the real-pty suite's flakiness make the shell job untenable; the fallback is Linux for `crates` and `frontend`, with macOS kept for `shell`.
