- **What.** The gate offers `opencode models` for an opencode seat, with "default (your opencode config)" first. A pick is written as `model` (`provider/model`) into the seat's `OPENCODE_CONFIG_CONTENT`; the default writes nothing. D-126 settles it at launch like any seat, and orch's brief names it (D-123).
- **Why.** The operator's call, 2026-11-02. On `opencode v2.2.5` the default command refuses `--model` (`opencode-spike-notes.md` §1), so the model channel is config, as `Posture::model_env` is for Claude Code. `OPENCODE_CONFIG_CONTENT` is the runtime override, above global and project config.
- **Accepted.** A model switched in the pane later is not seen by orch.
- **Reverses if.** The default command takes `--model`, in which case argv is the simpler channel.
