---
id: D-070
title: "an improve run targets a clone, never the live checkout"
phase: "meta"
status: alive
---

- **What was settled.** When the fleet is pointed at FLEETOR's own source (the improve run), the target is a **clone** — `git clone <repo> ~/fleetor-improve` — not the working checkout the app is running from. Reviewed work still merges to `fleet/integration` inside that clone (D-050 unchanged); the operator pulls from the clone into trunk themselves, deliberately, after a restart.
- **The failure it avoids is the file watcher, not the build.** Workers cannot break the running app: each works in its own worktree with its own `target/`, and reviewed branches never reach trunk, so nothing the fleet compiles is ever what the operator is executing. `orch` is the exception — its cwd is the target repo itself, and `tauri dev` watches `src-tauri/` with no `--no-watch` anywhere in this repo's config. An `orch` that edits a `.rs` file directly rather than delegating restarts the app underneath itself.
- **And a restart ends the run.** Panes are ptys the app owns; they die with it and there is no reattach. What survives is bounded and already built: `orphans.rs` kills the leaked `claude` processes at the next launch, and the run log rotates into `runs/` (D-058). So the cost of the crash is the whole live fleet, which is exactly the cost worth designing out.
- **The alternative was `--no-watch` on the dev launch.** One flag, and it leaves `orch` writing into the tree the operator is developing in — the isolation would depend on a launch argument nobody re-checks. The clone also makes a bad generation `rm -rf` rather than a git recovery, and it is the same shape workers already have (their own checkout, merges reviewed before they travel).
- **Not implemented, and nothing in code enforces it.** This is an operator procedure today: point the target picker at the clone. If live running shows the wrong target chosen by accident, the fix is a refusal at the target picker when the target resolves to the running app's own source — cheap, and worth waiting for evidence rather than guessing at.
