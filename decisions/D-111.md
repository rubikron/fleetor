---
id: D-111
title: "a reopened pane is given this launch's brief again; WP-27's rule R13 is reversed for the brief"
phase: S2
status: alive
---

- **What.** A reopen passes each pane this launch's brief. Claude Code: `--resume <id>` plus `--system-prompt <brief>` and `--system-prompt-snapshot off`. Codex: unchanged argv; placement already rewrites the brief into the pane's `config.toml` on every launch, and a test now holds that.
- **Why.** Found in a live reopen on 2026-10-07. Claude Code records the system prompt on a conversation's first request and reuses that record on every resume until compaction (its CLI reference, "System prompt flags in resumed conversations"). So with no brief on resume:
  - a pane that never had a turn has no record, and came up on the vendor's own prompt: four workers ran with no brief and none used `fleet`;
  - a pane with history keeps the brief of its first launch, so orch never saw the startup text D-109 renders for a reopen.
  Turning the recording off makes this launch's brief apply at once.
- **Reverses.** WP-27's R13 as it concerned the brief ("the session already holds the brief it was started with"). The rest of R13 stands: nothing else is injected into a resumed pane. `decisions.md` line 959 still records the old R13 wording.
- **Accepted risks.**
  - `--system-prompt-snapshot` needs Claude Code 2.1.257 or later and is passed unconditionally: the installed version is not readable where panes are spawned. An older Claude Code would likely refuse the flag and the reopened pane would not start. Not tested.
  - What turning the recording off costs in prompt caching is not documented and not measured.
  - Codex: its documentation does not say whether a resumed session reads instructions from the current config or from its recorded session. The config is right; whether codex uses it on resume is unverified.
- **Reverses if.** Reopened panes on Claude Code show a real caching cost, or a supported Claude Code version rejects the flag; then gate the flag on a version reading plumbed to the spawn path.
