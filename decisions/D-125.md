---
id: D-125
title: "the gauge divides by the window Claude Code runs: 1M with no model, 200k for an unrecognised slug"
phase: meta
status: alive
---

- **What.** (a) `model_window_tokens` returns Claude Code's own windows: 1,000,000 with no model, 200,000 for a slug it does not recognise. `WORKER_WINDOW_TOKENS` and `GaugeSource.window_env` are removed, because nothing exports a window to a pane since D-118. (b) An operator `launch.conf` override that still sets `[worker] model` or `base_url` is read and ignored without a warning (implemented in c1bd349).
- **Why.** Measured on Claude Code 2.1.307: a seat with no model on a plan login runs `claude-opus-5-5` at 1M, and an unrecognised slug runs at 200k when `CLAUDE_CODE_MAX_CONTEXT_TOKENS` is unset. The 500k in D-054 was true only while placement exported that variable to fleet-key workers, so every default worker's gauge was wrong after D-118.
- **Supersedes.** D-054.
- **Reverses if.** Claude Code's default plan model stops being natively 1M, or a seat again runs a model Claude Code doesn't recognise.
