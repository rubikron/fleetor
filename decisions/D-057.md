- **What changed.** The flat `docs/` tree is reorganized into four homes, and the layout becomes a documented system. Moves, so old paths in entries above resolve: `docs/{handoff,phase2-spikes,phase0-report,tui-pivot-plan}.md` + `phase0-report.json` and `docs/futureDesign/requirements/{MORNING-HANDOFF,OVERNIGHT-QUESTIONS,prompt-budget-menu}.md` → `docs/archive/` (superseded and one-off artifacts, banner-flagged, never edited below the banner); `docs/{tui-spawn,system-prompt,command-channel,context-gauge,peer-review,fence}-notes.md` and `docs/blackboard-shakedown.md` → `docs/notes/` (measurements, version-stamped evidence); `docs/futureDesign/requirements/` → `docs/roadmap/` (the WP system, now with an extracted `TEMPLATE.md`); `docs/futureDesign/vision_tenets.md` and `docs/futureDesign/plans/*.html` → `docs/roadmap/source/`. `docs/futureDesign/` is gone. New files: a root `CLAUDE.md` (dev-session orientation + the doc maintenance loop — this does not brush Tier 1.1, which forbids the *app* writing `CLAUDE.md` into the repo it operates on; panes never run with this repo as cwd), `docs/README.md` (the index every doc change updates), `docs/runtime-layout.md` (the `~/.fleetor` map), and WP-10 (the `ui/` architecture map, filed not written). This entry's preamble was also touched: the `BUILDING.md` filename corrected to `building.md`, and the pre-pivot "Standing defaults" paragraph marked historical — entries were not modified.
- **Why the default lost.** The organic layout mixed four kinds of document flat in `docs/`, hid the roadmap under `futureDesign/`, and had no index and no auto-loaded entry point — every fresh session paid an exploration pass before its first useful action, and stale copies of the same fact (budget numbers in four files) drifted independently.
- **What would reverse it.** The index rotting or the taxonomy going unfollowed within a few sessions — at which point the answer is fewer homes and a generated index, not more prose.
