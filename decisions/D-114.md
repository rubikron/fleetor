---
id: D-114
title: "the operator's release and remove forms offer to message the owner to stop; the not-taken-up clock ignores owners from an earlier run"
phase: S4
status: alive
---

- **What.** The release form and the remove form carry a checkbox, off by default, "message <owner> to stop work on it". Ticked, the UI sends that pane one operator message after the hub accepts the change. It is offered only when the owner is a pane of this session. `assignedAt` and the "assigned, never taken up" flag return nothing for an owner from another lineage.
- **Why.** A release or removal only writes the record, so in a live run the worker carried on. The message is one the operator chose to send, so D-110 holds: nothing is sent by the app on its own. An earlier-run owner is a pane that no longer exists, so a clock on it turned coral for nobody.
- **Not changed.** An agent's `fleet task release` or `remove` sends no message; orch tells the worker itself.
- **Reverses if.** Operators always tick it; the default then flips to on.
