id: D-126
title: "every seat's model is settled at launch, and Claude Code drops a slug it does not recognise"
phase: meta
status: alive
---

- **What.** `settle_models` checks the orchestrator and every worker, each fallback labelled with its own seat. A harness with a model list checks against it. With an empty list, Claude Code clears a slug that is not a `claude-` id or an alias (`sonnet`, `opus`, `default`, `fable`, `best`, `opusplan`, `haiku`, with or without `[1m]`) to the login's default and reports it; codex keeps a hand-typed name. The recognition lives in `claude_code_recognises` (`context_gauge.rs`), shared with `model_window_tokens`.
- **Why.** D-118 removed the fleet's DeepSeek key, so every worker runs on the operator's login and C9's reason for skipping workers is gone. A reopened run from before D-118 records workers as `deepseek-v4-flash`, which Claude Code passes to the Anthropic API, and the pane fails on its first turn.
- **Supersedes.** C9's rule that only the orchestrator seat's model is checked (decisions.md:845).
- **Reverses if.** A worker seat again runs on a credential other than the operator's own login, or Claude Code publishes a model catalog, in which case recognition should defer to it.
