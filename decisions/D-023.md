- **What:** A presentation-only refinement of the 4e-1 shell (no backend/contract change). Driven by an `impeccable` design critique (isolated design-review agent + the mechanical detector): removed the side-tab accent bars (the top AI-slop tell) from board cards and callouts — state is now cued by a full 1px border tint plus a foot dot/chip; unified the **blocked** signal to coral end-to-end (band cell outline+tint+gentle pulse, board dot/chip, feed rail, fleet edge) with gold reserved for review/pending/unread/cost; reserved motion for the one "needs you" signal (steady "alive" dots, only the blocked worker pulses); raised the a11y floor (AA-safe `--fg-mute`, dropped 9px steps, global `:focus-visible`, real tab/tabpanel roles); demoted the dev controls (`Run demo`/`Assign`) into a quiet top-bar `dev` toolbar. Added a **new Fleet topology view** (`ui/src/views/FleetGraph.tsx`) — a hand-rolled SVG (no node-graph library): lead centred, workers in an asymmetric signal-driven layout (blocked largest, idle smallest/dimmed), directional arrowheaded edges labelled with the real traffic (ticket id / `mail` / `ask_lead`), each non-idle edge carrying one message dot travelling in its true direction via SVG `animateMotion` — another consumer of the 4c bus, no new data. Wired **resizable + collapsible** panels (`react-resizable-panels`): a draggable terminal↔board divider with persisted sizes (`autoSaveId`) and a board that collapses to a slim expander rail. A faithful static sign-off mock lives at `docs/ui-redesign-preview.html`.
- **Why:** The 4e-1 shell was functional but read as AI-generated; the founder needs it pitch-worthy. The critique named concrete, convergent tells (detector + design review agreed the over-used left-accent-rail system diluted the one urgent signal), so the fixes were targeted, not a rewrite. Hand-rolled SVG over a library because a generic node-graph aesthetic is itself a slop tell and wouldn't sit on-theme (D-021-style "bespoke beats templated"); `react-resizable-panels` for the panels is a Tier-3 lib choice (built-in collapsible + persisted sizes, no hand-rolled drag math). Data honesty held: band metrics we don't yet track (model/context/elapsed) are omitted, not faked — they arrive with the live orchestrator (4e-2).
- **Deferred / open (stated):** the design is improved but not yet "pro" by the founder's bar — further visual polish is a later pass. Two IA questions left open in the mock's notes: whether the dev controls ship at all, and whether the queue cell should show something the board can't on the Tickets view. The Fleet edges light gold on *recent* mail (a glance at the newest feed entries), not a per-event pulse — a fuller event-driven flow is a 4e-2+ refinement.
- **Verified:** `tsc --noEmit && vite build` clean (45 modules). No `crates/`/`src-tauri` changes, so the 55 crate tests + the `fleet::demo` shell test stay green. The detector re-run over the mock is clear of the side-tab tell; two residual warnings (tight Operate-mode type scale, em-dashes in mock-only prose/sample feed lines) are defensible for the surface and don't apply to the shipped React copy. Live visual check (`npm run tauri dev`) is the operator gate, as before.
- **Reverses if:** the founder wants a different visual world entirely (then re-run `impeccable` new-work rather than refine this one); or the Fleet view needs interactivity (pan/zoom/drag, arbitrary topology) — at which point `@xyflow/react` earns its weight over the hand-rolled SVG.
