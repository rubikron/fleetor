- **What.** The seat config defines `agent.fleetor` (`mode: primary`, `prompt: "{file:<seat dir>/brief.md}"`) and sets `default_agent: "fleetor"`. One `orch.md`, one `worker.md` (D-042); only the carrier varies.
- **Why.** The operator's call, 2026-11-02: an agent's prompt is meant to replace opencode's default system prompt, the same kind of carrier as Claude Code's `--system-prompt` (D-043) and codex's `model_instructions_file`. `default_agent` because the default command refuses `--agent` (`opencode-spike-notes.md` §1). Rejected: `instructions` (appends, so the brief budget stops meaning the whole prompt); an `AGENTS.md` in the worktree (edits the target repo).
- **Not measured at the time of deciding** — see Measured below.
- **Reverses if.** The agent prompt appends, in which case the budget is restated or the carrier changes.
- **Measured 2026-11-02.** The prompt replaces opencode's base sections (`# Harness`, `# Communication`, `# Working in codebases`); `# Your Model` and `# Code Mode` (tool documentation) remain, as tool schemas remain under Claude Code's `--system-prompt`. It survives `/new`.
