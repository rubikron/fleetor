title: "Phase 6 (part): the docs stop describing a system that does not exist"
phase: "6"

- **The problem was the front door.** After Phase 5 the code was honest and the documentation was not. `README.md` was a phase-by-phase changelog of the headless fleet — MCP shim, ticket board, gate runner, Stop hook — none of which existed any more. `building.md` specified four seams (two of them deleted), a `tests/fake-claude` that had been removed, and a build-phase table for a product that had been replaced. `docs/fleet-comms-map.md` mapped six channels and a sync/async supervisor split. Anyone reading the repo top-down got the old system, confidently.
- **Rewritten, not patched:** all three. The comms map is now what its name promises — one `fleet send` followed from the model that typed it to the terminal it lands in, with a table of every failure and how it presents. `building.md`'s Tier 1 list gained the two invariants this pivot was actually organized around (nothing may delay or refuse a message; `accepted` never renders as delivered) and lost the ones that only made sense with headless workers (session = ticket, blocking calls point worker→lead).
- **Deleted rather than left lying around:** `examples/mcp-spike/` and `examples/stop-hook-spike/` (harnesses for machinery that no longer exists — runnable, and therefore worse than dead prose), `docs/architecture-ticket-flow.html` (a diagram of the deleted ticket flow) and `docs/ui-redesign-preview.html` (a sign-off mock of the board UI). `examples/tui-spawn-spike/` stays: it is the evidence behind `docs/tui-spawn-notes.md`, whose findings are still load-bearing.
- **Bannered rather than deleted:** `docs/handoff.md`, `docs/phase2-spikes.md`, `docs/phase0-report.md`. These are records of what was designed, spiked and measured at the time, and rewriting them would falsify the record. Each now opens by saying what is superseded and what survived — D-014's coordination-not-commands framing outlived the Stop hook that spiked it, and the Flash fidelity numbers are still why the worker panes run Flash.
- **Two stale references were real bugs, not prose:** a rustdoc intra-doc link in `bus.rs` pointed at the deleted `run_fleet`, and `pane.rs`/`message.rs` linked to the deleted `Party` and `crate::mail`. `cargo doc --workspace` now emits zero warnings, which is the check that catches this class.
- **What is deliberately still there:** every mention of the old architecture in a sentence explaining *what was removed and why*. Those are the most valuable comments in the codebase — `FleetGraph.tsx` saying `blocked`/`ask_lead` are gone because nothing blocks, `bus.rs` saying its tests no longer run behind a supervisor. Scrubbing those would delete the reasoning along with the reference.
- **Verified:** 55 workspace tests, 34 shell tests, `tsc --noEmit && vite build` clean, `cargo doc` clean, and no broken relative links between docs.
