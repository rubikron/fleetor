- **The board, the ticket cards, the worker transcripts and the queue figures are gone.** None of them describe a fleet of live TUIs; a ticket board is the interface to a supervisor, and there is no supervisor.
- **All five panes stay mounted**, three behind `.is-hidden`. Not an optimization to be reversed: there is no screen-replay in the backend, so unmounting an xterm destroys its buffer and the pane returns blank (L7). The resize nudge now fires on worker-tab change as well as view change, because switching worker 2 → 3 takes pane 3 from 0×0 to sized and its refit guard correctly refuses to fit at 0×0 (L8).
- **`useFleet` keeps two lists.** `feed` is a scrolling activity log and is bounded at 300; `messages` is unbounded. Dropping the oldest row of a log costs nothing; dropping the oldest message is a hole in the deliverable.
- **The event listener attaches before `bootstrap()`.** A Tauri `emit` with no listener is a drop, and bootstrap's first act is to append the notices that say where the fleet is working — so subscribing afterwards lost exactly the events that explain the target.
- **`accepted` renders as "undelivered to worker-3 — <reason>"**, never as a delivery and never as a failure to send (L3). Refused messages stay on the list, marked, rather than disappearing.
- **The spend gate is an overlay on the whole workspace**, since starting the fleet spawns five processes and four of them bill. It states the models, the count, the full target path, and — when no key is found — that the workers will not start at all rather than offering four seats that fail on spawn.
- **`FleetGraph` kept, two bugs of the same kind removed.** `blocked`/`ask_lead` is gone because nothing blocks any more, and `edgeKind` read only `e.to`, so worker→orch traffic never lit an edge — half the conversation in a product about conversation was invisible.
- **Deviation:** four sidebar views, not the two the plan specified. `topology` because FleetGraph has nowhere else to live; `activity` because the notices are the only surface for "the `fleet` binary was not found", "git worktree add failed" and "the socket is unavailable". I deleted `EventFeed` first and put it back — without it the shell looks fine while messaging is down, which is the failure mode this whole pivot is organized against.
