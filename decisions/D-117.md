---
id: D-117
title: "with no fleet running the Tasks view shows no tasks; the store is kept and returns with the next fleet on that target"
phase: meta
status: alive
---

- **What.** `fleet_tasks` returns no entries when no fleet is running, and does not open the gate target's store. `TaskBoard` renders no rows for a store that is not live and says "no fleet running · start one to see this repo's tasks". Nothing is deleted: the target's `tasks.db` is untouched and its tasks show again when a fleet launches on that target.
- **Why.** Operator's call, 2026-10-10: on opening the app, Home showed the last fleet's tasks with no fleet active, which read as live work. Amends D-104, which showed the gate target's store read-only with every control disabled.
- **Reverses if.** The operator wants to read a target's tasks before launching; then it comes back as an explicit view of a past target, not as the default.
